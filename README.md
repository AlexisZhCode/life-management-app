# Bloom — Life Management App

A warm, cute life management MVP for **iOS** and **Android**, built with Expo + React Native.

## Features

- **Tasks** — create to-dos by category, complete them, and review finished work
- **Care** — Sweet Rest (sleep rhythm), Little Sips (water), and Nourish (meals)
- **Rewards** — earn coins for completed tasks, habits, mood, and care rituals; redeem cozy treats
- **Habits** — daily habits with streaks
- **Mood** — soft daily emotional check-in with optional notes
- **Home** — today's overview, streak, and quick navigation
- **Local persistence** — data saved on-device with AsyncStorage

## Run

```bash
npm install
npm start
```

Then press `i` for iOS Simulator, `a` for Android emulator, or scan the QR code with Expo Go on your phone.

## Coin rewards

| Action | Coins |
|--------|-------|
| Finish a task | +5 |
| Complete a habit | +3 |
| First mood check-in of the day | +2 |
| Log sweet rest | +3 |
| Reach daily sip goal | +3 |
| Save a nourishing plate | +2 |
